# bestonehxh/homebrew-tap

Homebrew casks for SheepTerm and the Sheep family.

```bash
brew install --cask bestonehxh/tap/sheepterm
```

| Cask | App |
|---|---|
| `sheepterm` | [SheepTerm](https://github.com/bestonehxh/SheepTerm): SSH, serial and local shell terminal for network engineers |

SheepTerm updates itself, so `brew upgrade` skips it unless you run `brew upgrade --greedy`.
